# CADability.Forms API

The Windows.Forms implementation of the user interface of CADability. Start with <xref:CADability.Forms.CadControl>,
<xref:CADability.Forms.CadCanvas> and <xref:CADability.Forms.CadFrame>.

The classes of the geometry, the model and the actions are documented in [CADability](https://friendsofcadability.github.io/CADability/CADabilityDoc/api/index.html).
