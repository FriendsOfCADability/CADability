# CADability.Forms

CADability.Forms implements the user interface of [CADability](https://friendsofcadability.github.io/CADability/CADabilityDoc/index.html)
with Windows.Forms: <xref:CADability.Forms.CadControl> is a control that shows a CADability project, with
<xref:CADability.Forms.CadCanvas> as the view and <xref:CADability.Forms.CadFrame> as the frame, which connects the
project, the views, the actions and the property grid.

See the [API documentation](api/index.md) for all classes.
