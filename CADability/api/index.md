# CADability API

The classes of CADability by namespace. The most important ones:

- <xref:CADability.GeoObject>: the geometrical objects of a model, e.g. <xref:CADability.GeoObject.Line>, <xref:CADability.GeoObject.Ellipse>,
  <xref:CADability.GeoObject.BSpline>, <xref:CADability.GeoObject.Block> and the solids made of
  <xref:CADability.GeoObject.Solid>, <xref:CADability.GeoObject.Shell> and <xref:CADability.GeoObject.Face>.
- <xref:CADability>: the <xref:CADability.Project>, its <xref:CADability.Model>s and views, and basic types like
  <xref:CADability.GeoPoint>, <xref:CADability.GeoVector> and <xref:CADability.ModOp>.
- <xref:CADability.Actions>: the interactive actions, which construct and modify objects.
- <xref:CADability.Attribute>: layers, colors, line widths, line patterns and hatch styles.
- <xref:CADability.Curve2D> and <xref:CADability.Shapes>: two-dimensional curves and shapes.
- <xref:CADability.UserInterface>: the property pages and the abstraction of the user interface.

The Windows.Forms implementation of the user interface is documented in [CADability.Forms](https://friendsofcadability.github.io/CADability/CADabilityFormsDoc/index.html).
